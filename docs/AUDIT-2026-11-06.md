## 5. Temuan

### F1 — Settle tunai tanpa shift tidak masuk rekonsiliasi (DIPERBAIKI)
`/tables` hanya bisa diakses admin; admin yang belum membuka shift dapat
menyelesaikan tagihan meja tunai dan order tersimpan `shift_id = null`,
sehingga uang itu tidak pernah muncul di laci shift mana pun.

**Fix** (`src/lib/actions/tables.ts`): pembayaran tunai kini wajib shift
terbuka — "Buka shift dulu untuk menerima pembayaran tunai." Non-tunai tetap
boleh. Teruji dua arah: tanpa shift ditolak dan order tetap `open` (tanpa
penulisan parsial); dengan shift berhasil dan order teratribusi ke shift
(admin: order 200 → shift 34, kas seharusnya 205.550).

### F2 — Sync mobile memperbolehkan order tunai tanpa shift (DIPERBAIKI)
`pushOrder` menempelkan shift hanya bila kasir punya shift terbuka; kalau
tidak, order tunai tetap tersimpan `shift_id = null` (terbukti: order
168/169/172/174). Aplikasi mobile tidak punya layar shift, jadi menolak order
tunai akan mematikan alur offline.

**Fix** (`src/app/api/mobile/sync/route.ts`): di dalam transaksi (setelah
`pg_advisory_xact_lock`), bila kasir belum punya shift terbuka, shift dibuka
otomatis dengan kas awal 0 dan dipakai untuk order tersebut; order berikutnya
memakai shift yang sama. Penutupan tetap dari web (Shift → Tutup buku).
Teruji: dua order tunai berturut-turut tanpa shift → keduanya masuk shift
otomatis yang sama (order 232/233 → shift 67).

### F3 — `setup-db.ts` tidak memuat `.env` (minor, lokal saja)
Seed lokal memakai PIN default `123456`, bukan `SEED_*_PIN` dari `.env`
(karena seed hanya jalan saat DB kosong dan skrip tidak memuat env file).
Tidak berdampak produksi. Opsi: `tsx --env-file-if-exists=.env`.

### F4 — Crash PGlite setelah commit mengembalikan 500 (info)
Saat koneksi PGlite lokal mati setelah order ter-commit, API membalas 500
padahal data sudah tersimpan. Retry klien aman berkat idempotensi `clientId`
(terbukti: replay mengembalikan `exists`). Artefak lingkungan lokal.

### Nit yang diterima (tidak diubah)
- CSP `script-src 'unsafe-inline'` — syarat RSC Next.js.
- Sheet rincian `reports/export` memuat order terbuka/merged; sheet ringkasan
  tidak.
